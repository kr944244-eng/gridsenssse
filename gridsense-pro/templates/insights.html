The real-world problem

🌞Why grids become unstable

With more solar and wind, supply changes minute by minute. Smart grids balance this with dynamic pricing: when power is short, the price rises and people use less. But if homes, factories and plants react too slowly or too strongly, demand swings back and forth and the grid starts to oscillate.

⚠️What happens to people

Oscillations cause voltage and frequency swings. Protective relays then trip to save equipment, which means load-shedding, damaged appliances, stopped factories and hospitals running on backup. Predicting it early lets the operator act before anyone loses power.

🧠How this system helps

The operator enters one set of readings per location. The neural network predicts stability in milliseconds, rates the risk, and searches for the smallest changes (faster demand response, better tariffs, load shifting) that make the grid safe again.

📊The data

Decentral Smart Grid Control (DSGC) simulations of a 4-node star grid: 1 producer and 3 consumers (UCI / Kaggle). 10,000 simulations, each with the consumers in all 6 orders = 60,000 rows.

🧪Fair testing

Train and test sets are split by simulation, so copies of the same grid never appear in both. The raw stab value is removed to avoid label leakage, and p1 is removed because it equals total demand.

🏗️Architecture

Flask back end (login, SQLite history, prediction API, PDF reports, CSV batch processing) + HTML/CSS/JS front end. Model: scikit-learn MLP (128-64-32 neurons) with standard scaling.
